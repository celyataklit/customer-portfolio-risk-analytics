# Dataset

The original dataset used for this project contains approximately 985,000 banking transactions and exceeds GitHub's web upload size limit.

For repository optimization, the raw dataset is not included.

The project can be reproduced using any transactional banking dataset with a similar schema:

- TransactionID
- CustomerID
- CustomerDOB
- CustGender
- CustLocation
- CustAccountBalance
- TransactionDate
- TransactionTime
- TransactionAmount
